# 🏆 Colecionei: Gerenciador de Álbuns de Figurinhas

O **Colecionei** é uma aplicação web projetada para ajudar colecionadores a gerenciar, rastrear e organizar suas figurinhas da Copa do Mundo de forma simples, visual e eficiente. O projeto substitui as tradicionais tabelas de papel por um checklist dinâmico, responsivo e de rápida leitura.

A aplicação permite que o usuário controle o progresso da sua coleção por seleção, visualize rapidamente quais itens já foram conquistados e identifique o que ainda falta para colar no álbum físico.

---

## 🚀 Funcionalidades

*   **Checklist Dinâmico:** Organização de todas as seleções e seções especiais em um layout de grid intuitivo e scannável.
*   **Visualização por Categorias:** Organização estruturada para facilitar o rastreamento durante a colagem.
*   **Interface Responsiva (Mobile-First):** Design otimizado para dispositivos móveis, permitindo que o colecionador manuseie o álbum físico e marque as figurinhas conquistadas no celular simultaneamente.
*   **Controle de Progresso:** Indicadores visuais que atualizam em tempo real o status de conclusão de cada página.

---

## 🛠️ Tecnologias e Conceitos Aplicados

*   **HTML5 / CSS3 / JavaScript (ES6+):** Estrutura semântica e estilização moderna com foco em performance.
*   **UX/UI Design:** Layout planejado sob o princípio de *Clareza num relance (Clarity at a glance)*, reduzindo a sobrecarga cognitiva através de uma hierarquia visual limpa e códigos de cores para os status de marcação.
*   **Componentização Eficiente:** Arquitetura flexível e modular, preparada para escalar e suportar diferentes formatos de álbuns.
